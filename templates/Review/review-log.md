# Review log

One row per review round, filled in the same session. A row still "pending" after the session counts as rejected. An ASK counts as a finding: answered and applied is accepted; declined or still open at the end of the session is rejected ("ASK open"). If the review ran in the same session instead of a fresh subagent, write "same session" after the reviewer name.
