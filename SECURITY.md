# Security

## Reporting a problem
If you find a security problem in the kit, report it privately: on this
repository's **Security** tab, choose **Report a vulnerability**. Only the
maintainer sees it.

Please don't open a public issue for security problems, and never include
resumes, postings, or anything personal in a report.

Helpful to include:
- What you found and where (file, page, or feature)
- How to see it happen
- What someone could do with it

## What to expect
- A reply within a few days.
- If it's real, a fix in the next release, and credit in the release notes if
  you'd like it.
- For anything serious, the maintainer can pause updates for every kit at once
  while the fix is made (see `INCIDENTS.md`).

## Supported versions
Only the latest release gets fixes. The kit updates itself, so most people are
already on it.
